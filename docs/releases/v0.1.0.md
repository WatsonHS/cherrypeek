CherryPeek 0.1.0 是第一个公开预览版：面向高频提交场景（例如与编码 Agent 协作、一天提交几十上百次的仓库）的桌面 Git 历史浏览、统计分析与安全收口客户端。浏览分支和 worktree 全程只读、不会触发 checkout；白名单内的确定性收口操作仅在你显式点击时执行。

**要求**：Apple 芯片的 Mac，macOS 12 或更新，已安装 Git（Xcode 命令行工具自带的即可：`xcode-select --install`）。公开发布包经 Apple Developer ID 签名并公证。

**主要功能**
- 提交历史与分支图：按分支、标签或 worktree 连续浏览而不切换工作区；支持右缘时间滑轨、按提交密度着色的月历及分栏/图区拖宽，面向大仓库设计（已在 10 万提交、1000 个引用上测量）。
- 高频批次追踪与细粒度搜索：自动识别“上次更新”与“自上次查看新增”的完整拓扑批次（支持一键筛选、查看统计或交给 Agent）；支持按消息、作者 / 提交者、近 1 / 3 / 6 / 12 小时或精确到分钟的时间区间、OID 与路径组合筛选，配实时条件芯片条，并可一键定位到完整历史再返回结果。
- 提交详情、文件页与逐行追溯：一页查看完整消息与 trailer、作者与提交者、父提交、包含它的分支、改动概览与每个文件的语法高亮 diff（上下合并或左右并排、只看改动或完整文件）；按任意提交浏览目录树、路径历史、滑入式修改视图与逐行追溯（`git blame`）。
- 统计页（`⌘4`）：支持小时级与自定义精确到时分范围及批次切换，提供活动概览与周期对比（星期 × 小时热力图、提交节奏与类型、撤销与修正、分支活跃度）、改动量与仓库级可编辑排除列表（支持目录下钻）、关注项（反复修改、常一起改、单人维护目录、代码与测试及提交回查）、按需代码演化分析（估规模、代码年龄 / 当前归属 / 按周存活），支持在时间柱状图上拖动框选放大或带入提交页筛选。
- 工作区与审阅收口（M7）：实时查看已暂存、未暂存、未跟踪与冲突文件及其 diff；支持一键把未提交改动「交给 Agent」做只读审阅或整理提交，也支持单文件/全量暂存与取消暂存、二次确认丢弃单文件改动、自动恢复未提交草稿说明并创建提交（遇 Git hook 失败完整保留暂存区和输入说明）。
- 更新、推送、分支收口与轻量三栏合并（M5 / M7 / M8）：顶栏「更新 {分支}」先 Fetch 再安全快进（支持多远端选择、取消及同名未跟踪文件放行/备份/确认丢弃），并列提供可取消的非强制「推送 ↑N / 发布分支」；范围菜单与 `⌘K` 支持切换分支、新建分支、快进同步非当前分支、快进合入本地目标分支，以及删除已按祖先关系合入且未在任何 worktree 检出的本地分支。遇到分叉时，除一键「交给 Agent」外，还可在干净工作区下发起零写入隔离三方预演（无冲突时可选创建合并提交或保留原作者信息的单提交线性变基；10 个文件以内普通文本冲突可选打开 JetBrains 式左-中-右三栏双边箭头 `»` / `«` 视图点选并一次原子提交，中途取消零残留）。
- 交给 Agent 与原生桌面体验：全场景安全生成结构化交接 prompt（上限 256 KiB，支持上百至数千条新增提交的全量拓扑计数与首尾摘要）；支持已合入与等价补丁识别、跨页后退 / 前进（`⌘[ / ]`）、`⌘K` 快速跳转、`⌘O` 或拖入文件夹打开仓库、Finder / 终端 / 编辑器联动与远端网页打开，以及窗口位置记忆。

**已知限制**
- 目前仅提供 macOS Apple 芯片（arm64）版本；Intel Mac 与 Windows 尚未支持。
- 大仓库长时间连续运行的稳定性与常驻内存仍在持续优化验收中。
- 恪守安全收口边界：不自动 Fetch，不提供 `--force` 强制推送、`reset`、`stash`、多步或交互式 `rebase`、`cherry-pick`、`revert`、结构性/二进制/多共同祖先冲突解算，也不接手外部进行中的 `MERGE_HEAD` / `rebase-merge`；这些复杂情形均可通过交接入口一键交给 Agent 处理。

**数据**：缓存与搜索索引存放在 `~/Library/Application Support/CherryPeek`，绝不写进被查看的仓库；删除该目录即可清除应用保存的全部本地状态。

---

CherryPeek 0.1.0 is the first public preview: a desktop Git history browser, statistics explorer, and safe review-and-sync client built for fast-moving repositories (such as projects where coding agents commit dozens or hundreds of times a day). Browsing branches and worktrees is strictly read-only and never checks anything out; allowlisted operations run only when you explicitly click them.

**Requirements**: a Mac with Apple silicon, macOS 12 or later, and Git (the Xcode Command Line Tools are enough: `xcode-select --install`). Official release builds are Developer ID signed and notarized by Apple.

**Highlights**
- Commit history and branch graph: scope to any branch, tag, or worktree without touching your working tree; includes a right-edge adaptive time slider, commit-density calendar, and resizable split/graph columns, built for large repositories (measured with 100,000 commits and 1,000 refs).
- Batch tracking and fine-grained search: tracks topological batches since the last update or last visit (filter, open in Statistics, or hand off to an Agent in one click); filter by message, author / committer, 1h / 3h / 6h / 12h presets or minute-precise ranges, OID, and path with removable filter chips, and jump from any result into full history and back.
- Commit details, Files page, and blame: full message and trailers, author and committer, parents, containing branches, compact change summary, and syntax-highlighted per-file diffs (unified or side-by-side, changes only or full file); browse any commit's file tree, path history, slide-over change view, and line-by-line `git blame`.
- Statistics page (`⌘4`): sub-day and minute-precise custom ranges plus batch filters; activity overview with period comparisons (weekday × hour heatmap, rhythm, message types, revert/fix counts, per-branch breakdown), change totals with directory drill-down and per-repo exclusion rules, notable patterns (churn, co-changed pairs, solo directories, code without tests) with commit popovers, drag-to-zoom time bar charts, and on-demand code evolution (estimate, code age, ownership, weekly survival).
- Workspace and Review Gate (M7): inspect staged, unstaged, untracked, and conflicted files with diffs; hand uncommitted changes off to an Agent, or stage/unstage per file or in bulk, discard single-file changes with confirmation, recover pending commit drafts (`MERGE_MSG` / `SQUASH_MSG` / modified `COMMIT_EDITMSG`), and commit safely (hook failures keep your index and message intact).
- Updates, push, branch cleanup, and lightweight three-pane merge (M5 / M7 / M8): toolbar Fetch + fast-forward update (with per-remote fetch, cancellation, and safe handling of conflicting untracked files) paired with cancellable non-force push (`--set-upstream` for new branches); switch/create branches, fast-forward non-HEAD branches, fast-forward merge into a target branch, and delete ancestor-merged un-checked-out local branches. When branches diverge, preview the merge in an isolated zero-write object store: sync clean divergences via merge commit or author-preserving single-commit rebase, or resolve small ordinary text conflicts (up to 10 files) in a JetBrains-style left-center-right bilateral `»` / `«` view and commit atomically with zero `.git/MERGE_HEAD` residue if cancelled.
- Agent handoff and macOS integration: structured, injection-safe prompts up to 256 KiB (including full topological counts and head/tail summaries for large commit batches), merged status by reachability or patch equivalence, cross-page back / forward (`⌘[ / ]`), `⌘K` quick jump, opening repositories via `⌘O` or drag-and-drop, Finder / Terminal / Editor launchers, remote commit/branch web links, and persisted window bounds.

**Known limitations**
- macOS on Apple silicon (`arm64`) only; Intel Macs and Windows are not supported yet.
- Long-running stability and resident memory on very large repositories are still under ongoing validation.
- Intentionally excludes background auto-fetch, `--force` push, `reset`, `stash`, multi-step or interactive `rebase`, `cherry-pick`, `revert`, structural/binary/criss-cross conflict resolution, and taking over external in-progress `MERGE_HEAD` / `rebase-merge` states; hand those off to your Agent in one click.

**Data**: caches and the search index live in `~/Library/Application Support/CherryPeek`, never inside your repositories; delete that folder to remove everything stored by the app.

CherryPeek 0.1.0 是第一个公开预览版：只读的桌面 Git 历史浏览器，适合提交频繁（例如 Agent 一天提交很多次）的仓库。

**要求**：Apple 芯片的 Mac，macOS 12 或更新，已安装 Git（Xcode 命令行工具自带的即可：`xcode-select --install`）。应用已由 Apple 公证。

**主要功能**
- 提交历史与分支图，按分支、标签或 worktree 浏览，不切换工作区；面向大仓库（已在 10 万提交、1000 个引用上测量）。
- 提交详情一页看完：完整消息、作者与提交者、父提交、包含它的分支、改动概览和每个文件的 diff。
- 元数据搜索：消息、作者 / 提交者、日期、OID 与路径；结果可定位到完整历史再返回。
- 文件页：任一提交的目录树、文件或目录的历史、修改视图、逐行追溯。
- 工作区页：已暂存、未暂存、未跟踪与冲突的文件。
- 已合入状态（可达性，或 squash / rebase 后按补丁内容判断）、全局后退 / 前进、⌘K 快速跳转。

**已知限制**
- 只有 macOS Apple 芯片版；Intel Mac 与 Windows 尚未支持。
- 长时间运行的稳定性与内存表现还在验收中。
- 这一版只读：不提供 checkout、提交、合并、推送等操作。

**数据**：缓存与搜索索引在 `~/Library/Application Support/CherryPeek`，不会写进你的仓库；删除该目录即可清除。

CherryPeek 0.1.0 is the first public preview: a read-only desktop Git history browser for repositories that move fast (for example when coding agents commit many times a day).

**Requirements**: a Mac with Apple silicon, macOS 12 or later, and Git (the Xcode Command Line Tools are enough: `xcode-select --install`). The app is notarized by Apple.

**Highlights**
- Commit history with a branch graph, scoped to any branch, tag or worktree without switching your working tree; built for large repositories (measured with 100,000 commits and 1,000 refs).
- Commit details on one page: full message, author and committer, parents, branches containing the commit, a change summary and every file's diff.
- Metadata search over message, author / committer, date, OID and path; locate a result in the full history and come back.
- Files page: the tree of any commit, a file's or directory's history, a change view and line-by-line blame.
- Workspace page: staged, unstaged, untracked and conflicted files.
- Merged status (by reachability, or by patch content after squash / rebase), back / forward across pages, ⌘K quick jump.

**Known limitations**
- macOS on Apple silicon only; Intel Macs and Windows are not supported yet.
- Long-running stability and memory are still being validated.
- This version is read-only: no checkout, commit, merge or push.

**Data**: caches and the search index are stored in `~/Library/Application Support/CherryPeek`, never in your repositories; delete that folder to remove them.

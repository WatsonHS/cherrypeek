CherryPeek 0.1.0 是第一个公开预览版：以只读浏览为基础的桌面 Git 历史、统计分析与安全基础操作客户端，适合提交频繁（例如 Agent 一天提交很多次）的仓库。

**要求**：Apple 芯片的 Mac，macOS 12 或更新，已安装 Git（Xcode 命令行工具自带的即可：`xcode-select --install`）。公开发布包经 Apple 签名并公证。

**主要功能**
- 提交历史与分支图：按分支、标签或 worktree 浏览而不切换工作区；面向大仓库（已在 10 万提交、1000 个引用上测量）。
- 提交详情与工作区：完整消息、作者与提交者、父提交、包含它的分支、改动概览与每个文件的 diff；工作区页实时只读查看已暂存、未暂存、未跟踪与冲突文件。
- 元数据搜索与文件页：按消息、作者 / 提交者、日期、OID 与路径搜索并可定位到完整历史再返回；按任意提交浏览目录树、路径历史、修改视图与逐行追溯。
- 统计页（⌘4）：活动概览与周期对比、改动量与可编辑排除列表（支持目录下钻）、关注项（反复修改、常一起改、单人维护目录、代码与测试及提交列表）、按需代码演化分析（估规模、代码年龄 / 当前归属 / 代码存活），支持时间柱状图拖动框选放大或在提交页查看。
- 白名单基础 Git 操作：手动 Fetch（全部或指定远端，可选清理失效引用并支持取消）、当前或非当前本地分支快进更新（同名未跟踪文件可按规则自动放行、备份或确认丢弃）、切换分支与新建分支；遇分叉、未提交改动冲突或其他阻塞时不改动仓库（仅已完成 Fetch 时明确提示）并提供一键复制 Agent 交接 prompt；支持 Finder / 终端 / 编辑器打开与远端网页跳转。
- 桌面体验与导航：已合入状态（可达性或等价补丁）、跨页后退 / 前进（`⌘[ / ]`）、⌘K 快速跳转、`⌘O` 或拖入仓库文件夹打开、窗口位置与尺寸记忆。

**已知限制**
- 只有 macOS Apple 芯片版；Intel Mac 与 Windows 尚未支持。
- 长时间运行的稳定性与内存表现还在验收中。
- 不支持暂存（stage）、提交（commit）、合并分叉（merge）、rebase、reset、stash、推送（push）或冲突解决；需要这些操作时可通过交接入口交给 Agent。

**数据**：缓存与搜索索引在 `~/Library/Application Support/CherryPeek`，不会写进你的仓库；删除该目录即可清除。

---

CherryPeek 0.1.0 is the first public preview: a desktop Git history browser, statistics explorer and safe basic-operations client for repositories that move fast (for example when coding agents commit many times a day). Browsing leaves your working tree untouched, while whitelisted operations run only when explicitly triggered.

**Requirements**: a Mac with Apple silicon, macOS 12 or later, and Git (the Xcode Command Line Tools are enough: `xcode-select --install`). Official release builds are signed and notarized by Apple.

**Highlights**
- Commit history with a branch graph, scoped to any branch, tag or worktree without checking anything out; built for large repositories (measured with 100,000 commits and 1,000 refs).
- Commit details and Workspace page: full message, author and committer, parents, containing branches, change summary and per-file diffs, plus staged, unstaged, untracked and conflicted files.
- Metadata search and Files page: filter by message, author / committer, date, OID and path and jump back and forth to full history; browse any commit's tree, path history, change view and line-by-line blame.
- Statistics page (⌘4): activity overview with period comparisons, change totals and per-repo exclusion rules with directory drill-down, notable files/pairs/solo directories/untested commits with commit popovers, on-demand code evolution (estimate, code age, ownership and survival), plus drag-to-zoom or filter-in-commits on time bar charts.
- Whitelisted basic Git operations: explicit Fetch (all or a chosen remote, optional `--prune`, cancellable), fast-forward update for HEAD and non-HEAD branches (including identical pass-through or backup/discard choices for conflicting untracked files), branch switching and creation, Agent handoff when blocked or diverged, plus local app openers and remote commit/branch links.
- Desktop navigation: merged status (by reachability or patch equivalence), back / forward (`⌘[ / ]`), ⌘K quick jump, opening folders via `⌘O` or drag-and-drop, and persisted window bounds.

**Known limitations**
- macOS on Apple silicon only; Intel Macs and Windows are not supported yet.
- Long-running stability and memory are still being validated.
- Staging, committing, merging divergent branches, rebasing, resetting, stashing, pushing and conflict resolution are not included and can be handed off to an agent.

**Data**: caches and the search index are stored in `~/Library/Application Support/CherryPeek`, never inside your repositories; delete that folder to remove them.

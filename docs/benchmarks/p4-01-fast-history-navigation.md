# P4-01 快速滚动与时间拖动实测

日期：2026-11-09。本机定向前后对比，非发布 p95 或长时验收。

## 条件与方法

- 同一个十万提交 / 千引用宽图仓库：`output/fixtures/p2-01-wide-graph-20261108/wide-history`，HEAD 为 `d97a306fb4b8b27a1ff8754bd32b45e753cd6c25`。
- 同一完整元数据索引 profile：`output/benchmarks/p4-01-profile-20261108`。每次重新启动独立的 release Electron 窗口，1180 × 760；等待 renderer 的活动日期完整后测量。测量时不并行构建或运行测试。
- 六个不同时间上界，分别记录真实 preload IPC 时间、页面偏移及完整返回行的 SHA256。第一个请求包含日期拓扑缓存构建，后五个日期及页面不同，不是重复读取同一缓存页。
- 日期查询后，用真实键盘 / 滚轮把滑轨移到提交密集的六小时时段，24 次指针移动，名义间隔 50 ms，再释放。记录列表和滑轨不再 pending、选择与窗口不再变化的首次样本；100 ms 轮询，后续约 308 ms 的稳定确认另计。该指标不是精确到绘制的延迟。
- 回到最新后连续滚动六秒，名义速度 24,000 CSS px/s，实际约 21,000–22,000。25 ms 采样仅统计“正在加载且距已加载底部不超过 2 px”的等待；滚动停止即结束采样。
- RSS 为整个 Electron 进程树求和，可能重复统计共享页。拖动后的单点和五秒短时采样均不替代空闲 / 峰值 / 长时预算。

## 结果

| 项目 | 优化前 | 最终实现 |
|---|---:|---:|
| 第一次日期定位（含完整扫描），偏移 36,200 | 947.1 ms | 518.5 ms |
| 后续五个不同日期定位中位数 | 903.3 ms | 37.9 ms |
| 后续日期定位范围 | 823.2–970.0 ms | 28.8–60.3 ms |
| 滑轨释放到首次稳定样本 | 1457.9 ms | 105.3 ms |
| 六秒滚动中采到的边缘等待 | 0 ms | 0 ms |
| 滚动时主历史摘要峰值 | 1800 条 | 1800 条 |
| 滚动时提交 DOM 行峰值 | 37 行 | 37 行 |

六对页面的偏移、完整提交字段和图载荷摘要全部一致。滑轨前后使用相同的时间窗口与最终目标，最终选中同一 OID，落在偏移 20,000 的同一页。实际拖动时长为 1.42 / 1.56 秒，包含自动化事件往返开销。两版在本轮滚动强度下都未采到边缘等待，因此不宣称已经测得滚动卡顿减少或极端滚动达标。

## 内存代价与收敛

首个优化候选把后续日期查询降到 29–63 ms，但逐次 pointermove 随即替换整页，使拖动后 RSS 单点升到 826.2 MiB。最终增加约 120 ms 的预览请求合并，指针提示仍逐帧更新，首次与释放位置立即处理，原在途请求完成后优先处理最终位置。

最终拖动后 RSS 单点为 **787.9 MiB**，比该候选低约 38 MiB，但仍高于优化前的 **668.7 MiB**。其中 Rust 为 27.5 → 33.5 MiB，main 为 204.9 → 215.9 MiB，renderer 为 258.9 → 364.8 MiB。最终版五秒内 RSS 为 751.7–791.5 MiB；第五秒 main 活跃 JS 堆约 15.5 MiB、renderer 报告约 31.6 MiB，没有强制 GC。只能确认请求合并减少分配，不能据此认定其他增量都会很快归还或不存在长期增长。

保留本轮导航提速，但 **500 MiB 预算仍未达到，连续拖动后的 renderer 内存占用仍需优化**。日期缓存限制为 16 MiB，构建前释放原历史流；未扩大 renderer 摘要窗口。首次日期定位仍有完整扫描成本，缓存装不下的仓库回退精确扫描，本轮没有声称其速度相同。

## 检查与原始证据

- Rust 历史定向 14 项：首次 13 项通过，新增日期用例将“目标所在页”误写为“目标必在页首”；修正断言后该项独立复跑通过，未重复跑无关矩阵。覆盖乱序 / 同秒时间、前后页图等价、取消保留游标、预算拒绝与 shallow 变化失效。
- 自适应预取定向用例、TypeScript 检查、release 构建通过；实际滑轨最终定位与有界滚动通过上述实窗对比。没有执行完整平台 / 主题矩阵、超大仓库缓存回退性能或三十分钟测试。
- 正式前测：`output/benchmarks/p4-01-navigation-before-fixed-20261109.json`。
- 最终后测：`output/benchmarks/p4-01-navigation-final-20261109.json`；对照：`p4-01-navigation-comparison-final-20261109.json`（同目录）。
- 中间候选：`p4-01-navigation-after-20261109.json`、`p4-01-navigation-after-idle-20261109.json`，保留用于说明内存取舍；最初 `before-20261109.json` 因展开滑轨遮住“回到最新”按钮而未完成滚动，脚本改为先移开指针，并把拖动窗口从稀疏未来日期移到密集时段，未用该失败运行作正式前测。

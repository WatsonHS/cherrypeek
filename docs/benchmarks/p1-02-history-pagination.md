# P1-02：固定快照历史分页基线

日期：2026-11-07。真实 release daemon 的三轮完整遍历通过；每轮读取 100,000 条提交 / 500 页，逐页 OID 顺序与独立 Git topo oracle 一致。连续深页读取的核心接口耗时中位数为 18–19 ms；淘汰重读仍需重建遍历，约 0.38–0.45 秒。本报告不代表桌面滚动或发布性能验收。

## 环境与测量口径

- MacBookPro18,3，10 个物理 / 逻辑核心，32 GiB 内存；macOS 27.0.1，Node 26.0.0，Git 2.54.0（Apple Git-157，`/usr/bin/git`）。Rust 1.95.0 release 构建。
- 复用 seed `20261107` 的固定线性仓库：100,000 条提交、SHA-1、1 个引用；HEAD 为 `91081e9df378d40ab325f9c04b9cc4774b2c33ee`。1 个 pack / 100,002 个对象 / 19,951 KiB，无 loose object。目录 `output/fixtures/p0-03-seed-20261107/large` 未改动。
- 实现基于 `3113902` 后的工作区改动，测量时尚未提交。被测 release daemon SHA-256：`5b4dccdaabd7467dfa8dcba5febda400b302aa7d473fde7e7c87e1cdcefeee02`；原始 JSON 同时保存脚本、测试客户端、采样器和 manifest 哈希，测量后已核对一致。
- 每轮启动新 daemon，使用独立应用数据目录；完成打开后开始页请求计时。所有后续页使用上一页实际返回的游标，未通过构造 offset 跳到深页。每页 200 条，完整遍历后才测缓存和淘汰重读，不把这些额外请求计入完整遍历耗时。
- 单页 wall time 为请求发出到收到终止 `historyPage` 帧，包含 Git / daemon / stdio / 测试客户端处理；不包含 Electron 绘制。累计耗时为第一页请求到指定页完成。打开、握手及之后的缓存实验不计入累计遍历时间。
- OS page cache 未清理，独立 Git oracle 在计时前读取同一仓库；不称冷缓存。三轮串行执行，期间没有本项目构建或测试。正常系统后台负载未隔离。

## 连续遍历

每个目标页有 3 个样本。表中报告中位数与最大值，不用 3 个样本推断长期 p95；原始 JSON 的 nearest-rank p95 在此等于最大值。

| 页起点 offset | 单页中位 / 最大 ms | 累计到该页中位 / 最大秒 |
| --- | --- | --- |
| 0 | 397.23 / 409.18 | 0.397 / 0.409 |
| 10,000 | 17.97 / 29.28 | 1.501 / 1.562 |
| 50,000 | 17.89 / 28.80 | 5.509 / 5.540 |
| 90,000 | 19.18 / 29.00 | 9.438 / 9.623 |

完整 500 页耗时分别为 10.477 / 10.324 / 10.557 秒，中位 10.477 秒。三轮合计 1,500 页，主代理另核验了连续游标链、每页 200 条、总数量与末页终态。

首次页仍承担 topo 遍历启动成本，后续页复用流。与 [M0 基线](m0-baseline.md)的逐页重建实验相比，这证明持续遍历达到了本阶段目的；M0 是实验内部计时，本项是 daemon API wall time，不能直接计算严格的加速比。普通翻页 200 ms 是产品目标，本次只测其核心读取部分，UI 帧时间与大规模滚动留到 P1-03。

## 缓存与淘汰重读

缓存最多 8 页及 16 MiB 估算提交载荷。下表每项 3 个样本，按列出的顺序在每轮完整遍历之后执行。

| 操作 | 中位 / 最大 ms |
| --- | --- |
| 立即重读末页（offset 99,800，缓存命中） | 2.41 / 2.67 |
| 重读已淘汰的第一页 | 379.69 / 446.49 |
| 回退后重读原 90,000 游标（重建遍历） | 446.17 / 486.35 |
| 再次重读 90,000 页（缓存命中） | 2.44 / 2.49 |
| 之后重读 10,000 页（淘汰重建） | 394.62 / 402.17 |
| 之后重读 50,000 页（淘汰重建） | 410.18 / 417.35 |

原始记录中的后续 `target-replay@0` 与 `target-replay@90000` 当时已在缓存中，分别中位 2.42 / 2.41 ms，不能用它们代表任意深页首次读取。淘汰页超过普通翻页预算，P1-03 需要有限预取与明确加载反馈；本项不据此增加完整历史常驻数组或持久化图检查点。

## 整个核心进程树

每 100 ms 用 macOS `ps` 记录 daemon 及可观察到的 Git 子进程，包含打开、遍历、缓存实验和退出。该范围**不包含 Electron**，不得用来替代整个桌面应用的内存预算。

| 轮次 | 样本数 | 进程树峰值 RSS MiB | 累计 CPU 采样估计秒 |
| --- | --- | --- | --- |
| 1 | 126 | 49.14 | 4.10 |
| 2 | 123 | 49.17 | 3.90 |
| 3 | 125 | 49.06 | 4.03 |

峰值 RSS 中位 49.14 MiB、最大 49.17 MiB。RSS 求和可能重复统计共享页，短命 cat-file 可能落在采样间隔之外；CPU 是各已观察 PID 身份的累计时间估计，会漏掉短任务及退出前末段，不能称精确 CPU 总量。原始样本保留进程命令、PID、启动时间与分类，未只取 daemon 自身值。三轮均观察到根进程，采样错误为 0；daemon exit code 为 0、无退出信号，所有已观察身份自然退出，无强制清理。

  - 进展（2026-11-09）：“显示”菜单、左右并排（行内改动标记）、自动换行、悬浮历史列表和语法高亮已实现；语法高亮用 Shiki 4.5.0（MIT），JavaScript 正则引擎，在 Web Worker 中按语言分块加载，构建产物不含 eval / WASM。diff 变窄（容器宽度 ≤ 560px）时“第 n / N 处”与“显示”文字隐藏，只留箭头和图标。“完整文件”接口按[代码级计划](implementation/p4-11-diff-display.md)定义（`diffFullContext`）；daemon 已实现（2026-11-09），任一侧超过 5,000 行或 patch 编码后超过约 400 KiB 时返回 `RESOURCE_LIMIT`，renderer 自动退回只看改动。单元测试覆盖整文件上下文与超限拒绝。
  - 验收（2026-11-09）：
    - **完整文件模式**：在提交 diff（merge 的两个父提交、根提交、删除、改名、空文件）和工作区 diff（已暂存 / 未暂存、末尾无换行）上，都能由 patch 重建出两侧 blob，hunk 头的起始行和行数与 blob 一致；超过 5,000 行返回 `RESOURCE_LIMIT`（`pnpm test:pages`）。三个 store 收到 `RESOURCE_LIMIT` 后改用只看改动重读（renderer 单元测试）。

# P6-03 / P6-04 改动量与观察项代码级计划

日期：2026-11-12。依赖 P6-02 文件改动索引。

- stats.rs 复用 SearchQuery、时间范围和分桶；读取同一事务中的 commits 与 commit_changes，文件覆盖另算，merge 不计行数和文件数。
- 排除规则按仓库保存在应用数据目录：patterns 中无斜杠项精确匹配 basename，含斜杠项匹配完整路径，末尾斜杠匹配目录前缀，hex: 项精确匹配原始路径。默认常见锁文件；只从行数排除，文件数保留，单列排除行数。
- 计算增删 / 净增长、文件状态、目录下钻、作者目录、提交粒度、扩展名和代码 / 测试 / 文档；排名先完成全集计算再截断显示。
- 观察项：修改次数、最多 50 文件的共同改动对、仅一位作者的目录、改代码未改测试的提交。限制读入 250000 提交、2000000 文件记录、500000 文件对运算；超过预算返回 RESOURCE_LIMIT，不返回部分排名。
- 补 getStatsCommits 分页回查选择的文件、目录、文件对或未改测试提交，避免界面依赖截断的 OID 数组。
- 所有统计循环检查取消，沿用辅助调度；独立 Git 计算与仓库前后快照验证。不把“单人”“没有测试改动”当质量评价。

## 1. 说明

- 本文件是视觉与组件的实现依据。行为、数据口径与范围以 [PRODUCT](PRODUCT.md)「界面与交互」「数据口径」为准；两者冲突时，行为听 PRODUCT，视觉数值听本文件。

- 标注“M4”的内容不进入 MVP，见第 10 节。

## 5. 组件

### 顶部栏

从左到右：仓库名按钮（32 高，600）→ `/` 分隔（`--line2`）→ 浏览范围按钮（分支图标 + 名称 + 下拉箭头，32 高）→ worktree 入口（28 高、圆角 14、描边 `--line`，内容“工作区 · 名称”，空间充足时附 HEAD 与数量）→ 弹性空白 → 搜索框（34 高、宽 280、`--sunken`、右侧 `⌘K` 提示）→ 筛选按钮（34 × 34，有条件时 `--accent-soft` 底并带数量徽标）→ 更新提示。

工作区入口打开独立信息面板，展示路径、工作区类型、实际 HEAD 与快照时间；浏览范围入口负责历史范围选择，两者不共用弹层。所有 Popover 可点击外部或按 Esc 关闭；打开期间顶栏空白处接收点击，关闭后恢复窗口拖动。

更新提示：外层 `role="status"`，32 高、圆角 16、`--warn-bg` / `--warn`，13px。左侧“● 有 N 处更新 ⌄”是打开更新明细的链接，右侧独立的“刷新”按钮（24 高、圆角 12、`--panel` 底、12 / 600）。按钮不能放进链接里。

### 列表项

- 结构：左侧分支图（宽见第 6 节）+ 内容两行。第一行：摘要（单行省略）+ 右侧时间（12px `--text3`、等宽数字，不省略，各行对齐成一列）；第二行：头像 16 + 作者（空间不够时先省略）+ 右侧引用标签（小号）。
- 本窗口 HEAD 所在提交：图节点外加一圈同色描边（r 6.5、线宽 1.5），与引用标签里的 HEAD 图标对应；节点位于未显示的图线时不画。
- 悬停 `--hover`；选中 `--panel` 加选中阴影，`aria-pressed="true"`。
- merge 提交：摘要 400、`--text3`。
- 上次查看后新增：摘要前 7 × 7 圆点 `--accent`，`aria-label="上次查看后新增"`。
- “上次看到这里”行：高 30，分支线贯穿；中间是 1px `--accent`（不透明度 0.5）的线加“上次看到这里 · 今天 12:00”（11.5 / 500、`--accent-text`）。只在新增提交在顶部连续时出现。
- 列表顶部行：左为近期活动入口（7 根 4px 宽的小柱，`--line2`，今天 `--accent`，加“今天 N · 近 7 天 N”），右为“N 个新提交 · 拓扑顺序”。

### 引用标签 `.tag`

22 高、内边距 0 8、圆角 11、12 / 500；小号 18 高、内边距 0 6、圆角 9、11px。

同一提交上的引用和其他工作区的 HEAD 合成一组标签，按以下顺序排列：本窗口 HEAD → 在其他工作区检出的本地分支 → 其他本地分支 → 标签 → 其他工作区的 detached HEAD → 远端分支。

- 历史行只显示排在最前的一个标签（最宽 150），其余合成 `+N`。整组标签（含 `+N`）是一个按钮，悬停出现 2px `--line2` 外圈，打开时外圈为 `--accent`；点击打开弹层，列出这个提交上的全部标签，名称被省略、并入的远端或工作区路径都能在这里看到，不依赖悬停提示。详情区只有 `+N` 是按钮。弹层每项是标签加类型说明（如“本窗口 HEAD”“标签”“远端分支”），并入的远端单独一行，工作区附缩写路径。打开弹层不改变选中的提交；Esc 或点击外部关闭。标签组最多占第二行的 65%。
- 本窗口 HEAD 只用图标表示，不写“HEAD · ”前缀，分支名完整显示；detached 时文字为“HEAD”。
- 历史行里，与本地分支同名、指向同一提交的远端分支（如 `origin/main`，以及指向它的 `origin/HEAD`）并入本地分支标签，标签末尾加远端图标，悬停说明哪些远端也指向这里。详情区完整列出，不合并。
- 其他工作区：检出分支时，该分支标签改为 `wt` 样式；detached 时显示工作区文件夹名。悬停给出工作区名称与路径，路径不直接放进标签。
- 悬停（`title`）与读屏文字给出类型与完整名称，例如“本窗口 HEAD：main”“本地分支 review，已在工作区 review 检出（路径）”。

| `data-k` | 样式 | 用于 |
| --- | --- | --- |
| 默认 | `--sunken` 底、`--text2` | Author / Committer、Merge、二进制等说明 |
| `browse` | `--accent-soft` 底、`--accent-text` | 正在浏览的分支最新提交 |
| `head` | `--accent-soft` 底、`--accent-text`、600，前置 HEAD 图标 | 本窗口 HEAD 所在分支，或 detached HEAD |
| `ok` | `--ok-bg` 底、`--ok` | 与 origin 一致 |
| `wt` | 透明底、`inset 0 0 0 1px --line2`，前置文件夹图标 | 在其他工作区检出的分支，或其他工作区的 detached HEAD |
| 标签 | 默认样式，前置标签图标 | tag |
| 远端 | `--sunken` 底、`--text3`，前置远端图标 | 未并入本地分支的远端分支 |

## 6. 分支图

| 参数 | 数值 |
| --- | --- |
| lane 间距 / 首条线 x | 8 / 6（x = 6 + 8 × lane） |
| 图区宽 | 6 + 8 × (lane 数 − 1) + 6；3 线为 26，6 线为 52 |
| 线宽 | 1.5，圆头 |
| 普通节点 | 实心圆 r = 3.5，填充 lane 色 |
| merge 节点 | 空心圆 r = 3.5，填充 `--bg`、1.5 lane 色描边 |
| 节点纵向位置 | 列表项（高 60）中 y = 22，与摘要行对齐 |
| 日期行 / “上次看到这里”行 | 只画贯穿的竖线，高 34 / 30 |

连线规则（按行绘制，跨行连续靠相邻行端点对齐）：

- 贯穿的 lane：`M x 0 V 行高`。
- 从上方进入节点：同 lane 为 `M x 0 V 22`；从其他 lane 汇入为 `M xl 0 C xl 12, xn 12, xn 22`。
- 从节点向下：同 lane 为 `M x 22 V 60`；去其他 lane 为 `M xn 22 C xn 40, xl 38, xl 60`。merge 节点去第 N 父的曲线用目标 lane 颜色，分叉回父 lane 的曲线用节点所在 lane 颜色。
- lane 编号、每行的贯穿 lane 与上下连接由 Rust 输出（PLAN P2-01），renderer 只按上面的几何画；同一快照内前后翻页不改变 lane 编号和颜色。
- 颜色：lane n 用 `--l(n mod 6)`。
- 默认绘制前 6 列。图区“+N”为可点击按钮，`aria-label` 说明隐藏图线数量及点击展开；展开后绘制当前范围的全部图线，列表内部横向滚动；列表顶部出现一条 36 高的状态条（下边框 `--line`），左侧“全部图线 · N 列”，右侧“收起”按钮，在列表里按 Esc 也能收起。收起入口不浮在列表内容上。状态条出现和消失时，列表同步滚动相同高度，提交行在屏幕上的位置不变。切换保留行高、图线位置、颜色与纵向阅读位置。拖宽和悬停高亮见第 10 节。

## 9. 动效与可访问性

- 动效只有一个：部分结果的 2px 扫描条，`translateX(-100%)` 到 `translateX(330%)`、1.6s `ease-in-out` 循环；`prefers-reduced-motion: reduce` 时停止。其他状态变化不加动画。
- 用真实元素：`button`、`a href`、`input` 配 `label`（视觉隐藏的 label 也要有）；不要给 div / span 加 `role` 或点击事件冒充按钮。列表项是 `button`，选中用 `aria-pressed`；范围选择器与父提交切换用 `role="radio"` / `aria-checked`；标签页当前项 `aria-current="page"`。
- 更新提示与部分结果计数用 `role="status"`，错误用 `role="alert"`。
- 需要区分的颜色同时在明度或填充方式上不同（更新类型、文件状态、分支线），不只靠色相。
- 中文输入法组词期间不触发提交、快捷键、命令面板或复制。
- 支持文本选择、键盘焦点可见、系统缩放和深浅主题；深浅主题共用同一套 token 名。

## 10. M4 体验增强

以下内容在画布上已有画板，但不进入 MVP，按 PLAN 的 M4 任务实现。

### 宽分支图交互（M4）

- 图区宽度可拖：图区右侧手柄（`aria-label="调整分支图宽度"`），默认显示 4 条线，最多 12 条。
- `+N` 展开与收起已先按六列 / 全部图线模式接入；后续拖宽可复用该入口。折叠不将多条隐藏关系画成一条虚假的合并连线。
- 悬停或选中某个提交时，它所在的线保持全色，其他线不透明度 0.4（0.25 时整张图过灰，渲染检查后调整）。
- 画板参数：lane 间距 9、首条线 x 7、左栏约 520。收起与展开不改变 lane 编号与颜色。

### 窄窗口（M4）

- 窗口宽度不足 1100px 时只保留提交列表；详情作为右侧抽屉，宽 560，位于顶部栏与状态栏之间，左侧阴影 `-14px 0 36px rgba(20,20,18,.18)`，列表上盖 `--scrim` 遮罩。
- 抽屉顶部有关闭（`aria-label="关闭详情"`，Esc 同效）、上一个、下一个按钮；内容为概览的精简版。
- 顶部栏收缩：搜索变成图标按钮（`aria-label="搜索 ⌘K"`），worktree 入口只显示文件夹图标与 HEAD 分支，更新提示缩成带圆点的数量。

### ⌘K 命令面板（M4）

- 居中浮层，宽约 600、圆角 12、阴影 `0 24px 60px rgba(20,20,18,.24)`，下方 `--scrim` 遮罩。
- 结果按“提交 / 分支 / worktree / 命令”分组，无匹配的分组不显示；命中文字用 `<mark>`；每条右侧显示快捷键 `kbd`（最小宽 22、22 高、圆角 5、描边 `--line2`、`--sunken` 底、12px）。
- 底部提示“↑↓ 选择 · ↵ 打开 · Esc 关闭”。
- 快捷键说明卡（浏览、查找、范围与刷新、其他四组）属于 MVP（PLAN P2-04）；命令面板本身属于 M4（P4-07）。说明卡里“前后切换”对应 ⌘[ / ⌘]，“切换标签页”对应 ⌘1 / ⌘2。

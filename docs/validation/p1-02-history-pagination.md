# P1-02：历史分页与手动刷新验收

日期：2026-11-07。状态：已通过本机 macOS 技术验收。实现基于 `3113902` 的 UI-02；契约与代理分工见[代码级计划](../implementation/p1-02-history-pagination.md)。此阶段保留现有界面设计，接通当前 HEAD 范围的翻页和刷新；不代表 MVP 或发布性能已经验收。

## 本项行为

- 打开时冻结完整 HEAD OID；持续读取一次 Git topo 遍历，连续下一页不使用 `--skip`。第一页、重复读取和淘汰重读均有明确游标，缓存最多 8 页 / 16 MiB 估算载荷。
- UI 每页默认 200 条，上一页 / 下一页替换当前页面。读取期间保留旧页，可取消；失败重试原请求。分组数量和临时前端图只描述本页。
- 刷新先准备新快照的第一页，再原子替换会话；失败保留旧页面。新提交不会自动插入正在阅读的列表。所选提交或滚动锚点没在新页中时说明“当前页未载入”，不据此推断已不可达。
- shallow / grafts 边界改变时返回 `SNAPSHOT_CHANGED`；缺失对象保持错误状态，不自动 fetch。查看记录校验界面实际显示的 generation。

## 审查中的修正

1. 将已发行的最深游标位置与当前 Git 流位置分开；回读淘汰页后，先前拿到的深页游标仍可使用。
2. 取消或解析失败后回收当前流，但保留完成页和 query 身份。页读取与输出受同一个有界查询保护，清理完成后才报告取消终态。
3. 刷新响应的 envelope 仍回显请求的旧上下文，新 session 放在业务载荷中；完整终态后 main 才切换上下文，不放宽所有响应的判旧规则。
4. 翻页失败的重试保存失败请求的游标；刷新失败单独恢复刷新。旧详情保存原观察时间，查看记录只在实际显示对应会话时更新。
5. 500 条长摘要覆盖多帧背压；正常响应超出输出队列长度时不得丢帧或断开连接。
6. 真实窗口发现页尾刷新时，新页最大滚动距离不足以恢复旧锚点。只补所需的有界尾部空白，翻页 / 新请求时清除；再用实际 OID 与像素偏移断言验证，不放宽偏移检查掩盖跳动。

分块输出取消用例在第一块非终止 `historyPage` 到达后暂停 stdout，发出取消并在 150 ms 后恢复接收；确认返回 `CANCELLED`、原 Git PID 已退出，再重试得到完整 500 条及至少 20 个数据块。500 条长摘要的普通读取和刷新均检验有界多帧传输，刷新 envelope 保持请求上下文，覆盖计数只计提交。

首轮测试失败涉及夹具中的缩写 OID、阻塞 gate、wrapper 路径匹配与清理逻辑；修正测试后完成全量回归，没有将失败尝试计为通过证据。

Renderer 用例覆盖失败页的同游标重试、取消保留当前页、刷新失败保留会话、刷新成功后旧选择 / 原观察时间 / 锚点缺失、新页面显示后记录查看、刷新提交后切仓失败仍保留新页面，以及快速刷新被后续切仓取代。协议用例检查分块与新会话、取消后排空而不发布数据、已提交刷新迟到时同步 main 上下文。

真实窗口先在 205 条提交仓库往返第一页 / 第二页；外部追加一条后刷新，确认新 HEAD、200 条边界、旧选择保留及原滚动 OID / 偏移；再追加 30 条，确认旧锚点不在新页时明确提示。每次外部 Git 变更后重新取只读基线，翻页与刷新前后仓库快照相同。截图：`output/playwright/p1-02-history-pagination.png`；主代理已查看，刷新与页码可见，P3-03 更新数量保留显式占位标签。复测命令为 `pnpm build && pnpm test:smoke:history`。

正式性能测量以同一 release daemon 串行完成三轮 100,000 提交 / 500 页，全部逐页匹配独立 Git oracle，进程自然退出。连续深页核心接口中位 18–19 ms，淘汰第一页与 90k 页重读中位分别为 380 / 446 ms；整个 daemon + Git 树采样峰值 RSS 最大 49.17 MiB。每项仅 3 个样本，CPU / RSS 为有缺口的进程树采样，不包含 Electron。口径、原始产物与首次预检脚本失败记录见[分页基线](../benchmarks/p1-02-history-pagination.md)。

## 范围限制

- 当前只支持 `head` 范围，分支 / 标签 / 全部分支与 worktree 导航属于 P1-04。
- 当前为显式翻页，虚拟列表、自动预取及上次查看新增标记属于 P1-03。
- 前端临时图不提供跨页 lane 连续性；Rust 图布局属于 P2-01。
- 选择或锚点不在新第一页时只保留旧详情并说明未载入；跨全范围 OID 定位仍待后续实现。
- 只有手动刷新，自动变化通知、更新明细属于 P3-03；界面中的占位示例不作为已实现证据。
- 本机 macOS / Apple Silicon 验证不代表 Windows 或发布包验收。Git 内部遍历内存与临时缓冲不等于应用缓存额度；性能测量单列整个 daemon 与 Git 进程树。

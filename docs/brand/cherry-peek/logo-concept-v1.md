## 设计

- 樱桃果梗与 Git 分支线合为一体，交汇圆点对应提交节点。
- 一颗实心樱桃、一颗空心樱桃；空心圆呼应选中提交，也带出 Peek 的观察意味。
- 使用樱桃红图形和深炭色字标，品牌显示名称为「Cherry Peek」。
- 当前交付为透明背景 PNG，1254 × 1254。此文件是栅格概念稿，不是 SVG 源文件。

## 完整提示词

```text
Use case: logo-brand.
Asset type: original logo concept for "Cherry Peek", a desktop Git history browser for developers working alongside coding agents.
Primary request: Design a refined, memorable emblem combining a pair of cherries with a Git branch graph. The cherry stems themselves should be the graph paths, not a separate Git icon pasted inside fruit. Two slightly staggered cherry-red round fruit/commit nodes hang from one beautifully balanced curved branching stem. One fruit is solid; the other is a generous hollow ring, subtly suggesting both a selected commit and a peephole ("Peek"). A tiny simple leaf can complete the cherry silhouette if it helps, but keep the mark extremely economical.
Style: expertly drawn flat vector-like identity, bold clean geometry, precise optical balance, friendly but sophisticated developer tool, confident consistent strokes, strong silhouette, meaningful negative space. The symbol must remain recognizable at app-icon size.
Composition: a single centered stacked logo lockup on a genuinely transparent background. Large emblem above, exact wordmark "Cherry Peek" beneath, ample breathing room. The emblem is the hero. Balanced, compact square composition. Do not add a rounded-square app tile or presentation board.
Palette: deep warm cherry red for the emblem, dark warm charcoal for the wordmark. Maximum two solid colors; no green.
Typography: custom-feeling contemporary humanist sans serif, medium weight, slightly rounded details, careful kerning, exactly "Cherry Peek" in title case, with a visible word space.
Avoid: gradients, shading, 3D, glossy fruit, realistic illustration, drop shadows, stock cherry clip art, literal eyeballs, faces, mascots, code brackets, magnifying glasses, extra icons, decorative grids, taglines, watermarks. Do not imitate any existing cherry software logo. Make the branching graph structure do the visual work.
```

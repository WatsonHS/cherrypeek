# CherryPeek

中文 | [English](README.en.md)

桌面 Git 历史浏览器，适合提交频繁的仓库，比如 Agent 一天要提交很多次的时候。一眼看清最近提交了多少、谁提交的、改了什么、分支之间是什么关系。浏览时不改动工作区，基础 Git 操作需单独点击执行。

> **状态：早期预览版（0.1）。** 目前只支持 Apple 芯片的 Mac。只读浏览的功能已经齐全；长时间运行的稳定性、Windows 和 Intel Mac 还没有覆盖。名字取自 cherry-pick 的谐音：挑着看一眼提交，什么都不改。（早期文档里叫 CommitScope，代码内部标识仍沿用 `commitscope`。）

## 能做什么

- **提交历史**：带分支图的提交列表，为大仓库设计（在 10 万提交、1000 个引用上测过）。可以按任一分支、标签或 worktree 浏览，切换时不会 checkout。
- **提交详情一页看完**：完整消息和 trailer、作者与提交者、父提交、包含它的分支、改动概览，下面是每个改动文件的 diff（上下合并或左右并排，只看改动或完整文件）。
- **搜索**：按消息、作者 / 提交者、日期、OID 和路径筛选，基于本地索引；索引还在建时结果也不会乱跳。任一结果都能定位到完整历史里看前后提交，再回到结果。
- **文件**：浏览任一提交的目录树，旁边是文件或目录的历史；点开某次修改，修改视图从左侧滑入盖住文件；支持逐行追溯，能在一个提交改动的所有文件之间切换。
- **工作区与审阅收口（源码版）**：查看当前 worktree 里已暂存、未暂存、未跟踪和冲突的文件及其 diff；支持「交给 Agent」一键生成未提交改动的只读审阅或整理提交提示词，也支持按文件/全量暂存与取消暂存、二次确认丢弃单个未暂存/未跟踪改动、自动载入未提交草稿并审阅提交说明后创建提交（如被 Git hook 拦截会完整保留暂存区和输入说明，并引导交给 Agent 修复）。
- **统计（⌘4）**：按时间范围与周期对比查看提交活动（含星期 × 小时热力图、提交节奏与类型、撤销与修正、分支活跃度）；查看改动量、热点目录/文件与可按仓库编辑的排除列表（支持目录下钻）；查看反复修改、常一起改、单人维护目录和代码与测试；按需在选定目录或文件上计算代码年龄、当前归属和按周存活。支持在时间柱状图上拖动框选区间放大，或在提交页筛选对应提交。
- **已合入状态**：按可达性判断分支是否已合入默认分支；squash 或 rebase 合入的，按补丁内容判断。
- **导航与桌面体验**：跨页面的后退 / 前进（⌘[ / ⌘]），⌘1 / 2 / 3 / 4 切换页面，⌘K 快速跳到提交、分支和 worktree；支持 `⌘O` 或直接拖入仓库文件夹打开，并记住窗口位置与尺寸。每个快捷键在所有页面含义一致，完整列表在顶栏的键盘图标里。
- **交给 Agent**：一键复制写好的提示词，让 Agent 审阅某个提交、解释一次合并、审阅工作区未提交改动，或审阅某个时间点以来的所有提交。
- **更新、推送与分支收口操作（源码版）**：顶栏“更新 {分支}”先 Fetch，再将当前工作区的分支快进到上游；领先上游或尚未发布的新分支会在顶栏旁显示“推送 ↑N / 发布分支”（非强制推送，远端拒绝或已分叉时安全停下并交给 Agent），推送期间支持取消。范围菜单与 `⌘K` 中可切换分支、新建分支、快进同步非当前分支、将特性分支快进合入本地目标分支（可选同步切换过去），并可直接删除已按祖先关系合入且未在任何 worktree 检出的本地分支；仅补丁等价或已被检出的分支继续交由 Agent 核实清理。分叉、无上游或会覆盖未提交改动时拒绝执行并保持工作区安全；遇到同名未跟踪文件时可择一备份、确认丢弃或直接放行。

## 浏览与基础操作

- 浏览分支不会切换工作区。当前源码版只执行白名单内的确定性收口操作：手动 Fetch、快进更新与快进合入、切换与新建分支、删除已按祖先合入且未检出的本地分支、非强制推送与工作区文件级暂存/确认丢弃/提交；仍不包含自动 Fetch、`--force` 强推、`reset`、`stash`、多步 `rebase` / `cherry-pick` / `revert` 或接管进行中的冲突合并，复杂情形均一键交给 Agent 处理。
- 仓库里的内容一律当作不可信的文本处理，窗口运行在沙箱里。
- 缓存和搜索索引存在 `~/Library/Application Support/CherryPeek`，不会写进你的仓库。删掉这个目录就能清除应用存下的所有数据。

## 安装

1. 从 [Releases](../../releases) 下载 `CherryPeek-<版本>-arm64.dmg`（已经过 Apple 签名和公证）。
2. 打开后把 CherryPeek 拖进“应用程序”。

要求：Apple 芯片的 Mac，macOS 12 或更新，已安装 Git（Xcode 命令行工具自带的就够：`xcode-select --install`）。

## 从源码构建

需要 Node.js（版本见 `.node-version`）、pnpm 10、Rust 工具链（见 `rust-toolchain.toml`）和 Git。

```sh
pnpm install
pnpm dev                 # 构建并启动
pnpm start               # 启动上一次的构建
pnpm package:mac         # 为本机打一个未签名的 .app / .dmg，放在 release/
```

签名发布用 `pnpm release:mac`，见[发布流程](docs/RELEASE.md)。
